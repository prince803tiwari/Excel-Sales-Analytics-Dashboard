# 📊 Excel Sales Analytics Dashboard

An interactive Sales Analytics Dashboard built using Microsoft Excel, PivotTables, PivotCharts, Slicers and VBA automation.

## 🚀 Features

- Interactive Region Slicer
- Multiple Dashboard Views
- PivotTables & PivotCharts
- Sales Performance Analysis
- Target Hit %
- Away From Target %
- Dashboard navigation
- VBA/Macro automation
- Dynamic Slicer-PivotTable connections

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- VBA
- Macro Recording
- Data Visualization

## ⚙️ VBA Automation

The project uses VBA to dynamically connect or disconnect the Region Slicer with different PivotTables based on dashboard selection.

Main VBA procedure:

`SlicerConnection`

## ▶️ How to Use

1. Download the `.xlsm` file.
2. Open it in Microsoft Excel.
3. Enable Macros/Content.
4. Open the Dashboard sheet.
5. Use the dashboard controls and Region Slicer.

## 🎯 Project Objective

To build an interactive Excel dashboard for analyzing sales performance and demonstrate Excel automation using VBA.
